================ HTTP STATUS CODES =================

+-----+----------------------+-----------------------------------+-------------------------------+
|Code | Name                 | Simple Definition                 | Example                       |
+-----+----------------------+-----------------------------------+-------------------------------+
|200  | OK                   | Request successful                | Login successful              |
|201  | Created              | New data created                  | User registered               |
|204  | No Content           | Success, but no data to return    | Product deleted               |
+-----+----------------------+-----------------------------------+-------------------------------+
|400  | Bad Request          | Invalid request from client       | Missing required fields       |
|401  | Unauthorized         | User not logged in                | JWT token missing             |
|403  | Forbidden            | No permission to access           | Normal user opens admin page  |
|404  | Not Found            | Requested resource not found      | Product ID not found          |
|405  | Method Not Allowed   | HTTP method not supported         | GET used instead of POST      |
|409  | Conflict             | Data already exists               | Duplicate email registration  |
|422  | Unprocessable Entity | Validation failed                 | Invalid email format          |
+-----+----------------------+-----------------------------------+-------------------------------+
|500  | Internal Server Error| Server-side error                 | Database connection failed    |
|502  | Bad Gateway          | Invalid response from server      | Proxy server issue            |
|503  | Service Unavailable  | Server temporarily unavailable    | Server under maintenance      |
|504  | Gateway Timeout      | Server took too long to respond   | Backend timeout               |
+-----+----------------------+-----------------------------------+-------------------------------+

============== MOST USED IN MERN ==============

200 -> Data fetched successfully
201 -> New document created
400 -> Bad request (missing/invalid data)
401 -> Token missing or invalid
403 -> User has no permission
404 -> Data not found
409 -> Duplicate data
500 -> Server error
